Info About the Pages:

The Home page was made using JavaScript and EJS provides navigation to the courses pages. The courses page was made using JavaScript, EJS, and Express. It allows users to view their course entries while providing options to create(add), read, update (edit), and delete entries. MongoDB was used to create the database to store each course entry, each entry made on the website or on MongoDB itself has multiple text fields to fill out (clasName, taskDescription, taskType, dueDate, levelOfCompletion, and notes).

Extra Notes: -This assignment was developed using a full stack setup which included Express.js and Node.js for the backend or server side, MongoDB for data storage, and Bootstrap/Font Awesome for the styling and icons on the actual webpage.
